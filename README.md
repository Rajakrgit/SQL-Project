# SQL-Project
This project was SQL Query Practice and Problem Solving. The main objective was to strengthen my SQL skills by solving problems ranging from basic queries to advanced analytical questions.

I followed a structured learning roadmap using platforms such as W3Schools, SQL-Practice, HackerRank, DataLemur, and SQLZoo.

During the project, I practised commands such as SELECT, WHERE, ORDER BY, GROUP BY, and HAVING. I also worked with aggregate functions, joins, subqueries, Common Table Expressions, and window functions.

Some of the problems involved finding the second-highest salary, identifying employees earning more than their managers, finding customers who never placed orders, and ranking salaries within departments.

One of the main challenges was solving questions that required multiple tables or more advanced query logic. I learned to break the problem into smaller steps, identify the required tables and conditions, and validate the output.

Another important learning was that joins, NULL values, and duplicate records must be handled carefully to avoid incorrect results.

To improve the project further, I would apply these SQL techniques to a real business dataset, create a relational database, and connect the analysis to a Power BI dashboard.

Overall, this project improved my SQL knowledge, analytical thinking, and ability to solve database problems systematically.
